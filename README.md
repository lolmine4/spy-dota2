# Шпион по Доте

Браузерная игра для компании в Discord. Все игроки видят одного героя или предмет из Dota 2, кроме шпиона. По очереди задаёте друг другу вопросы, ищете, кто не в теме, и голосуете. Шпион тем временем пытается понять, что загадано.

Голос остаётся в Discord, а сама игра идёт в браузере: хост создаёт комнату и кидает ссылку в чат, остальные заходят с ПК или телефона.

## Правила

- Все, кроме шпиона, видят одну карточку. Шпион видит только то, что он шпион.
- Спрашиваете по очереди: в начале раунда игра перемешивает игроков и показывает очередь. Тот, чей ход, задаёт вопрос любому игроку и жмёт «Передать ход». Тех, кто не в сети, очередь пропускает. Хост может передать ход за игрока, который завис.
- Любой игрок может запустить голосование. Чтобы выгнать игрока, нужно больше половины голосов игроков онлайн.
- Если выгнали шпиона, у него есть минута, чтобы назвать карточку. Угадал — победа шпиона, не угадал — победа агентов.
- Если выгнали своего, побеждает шпион.
- Шпион может в любой момент нажать «Я знаю, что загадано». Ошибся — проиграл.
- Когда кончается таймер, сразу начинается голосование. Если большинство не набралось, побеждает шпион.
- Очки: каждому агенту по 1 за победу, шпиону 2.

Настройки хоста: что загадываем (герои, предметы или всё вместе), один или два шпиона (второй появляется от 6 игроков), таймер на 5, 8, 10 минут или без него.

У каждого игрока внизу есть сетка всех вариантов. По карточкам можно нажимать, чтобы вычёркивать их, а шпион через ту же сетку выбирает ответ.

## Запуск у себя

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

Игра откроется на http://localhost:3000. Друзья с других компьютеров так не зайдут, для этого нужен деплой.

## Деплой на Render (бесплатно)

1. Залей папку в репозиторий на GitHub.
2. На [render.com](https://render.com) нажми **New → Blueprint** и выбери репозиторий. Render прочитает `render.yaml` и создаст бесплатный веб-сервис.
3. Через пару минут игра будет доступна по адресу вида `https://dota-spy-xxxx.onrender.com`.

Бесплатный сервис засыпает, если 15 минут никто не играет. Первое открытие после этого занимает около минуты. Пока у кого-то открыта игра, сервер не спит. Комнаты хранятся в памяти, поэтому сон или новый деплой их стирает: нужно просто создать новую.

## Обновление героев и предметов

Список берётся из официального фида dota2.com, а магазин — из файлов игры (зеркало [dotabuff/d2vpkr](https://github.com/dotabuff/d2vpkr)). После патча, где добавили героя или поменяли магазин:

```bash
npm run build-data
```

Скрипт перезапишет `public/data/pool.json`. Закоммить его и задеплой.
